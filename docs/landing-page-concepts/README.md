# Landing page concepts

Open `index.html` in a browser. The top control swaps between three independent landing-page directions.

- **Pin entry** leads with the product's most unusual interaction, tapping the pins still standing.
- **The 10 pin** starts with the problem of reconstructing a move after the night is over.
- **Game plan** starts before league and puts the history at a house or pattern first.

The mockups use `[APP URL]`, `[HOUSE]`, `[PATTERN]` and `[BALL]` where a real deployment value or a user's own value is needed. They do not include invented performance statistics, customer claims or fabricated testimonials.
