the time of writing, their checkboxes were never ticked back, and several
decisions in them were reversed during implementation. The current state lives
in the code, and the reasoning that survived lives in `../DECISIONS.md`,
`../ARCHITECTURE.md`, `../DATA_MODEL.md` and `../DESIGN-LANGUAGE.md`.

when an ADR points here.
