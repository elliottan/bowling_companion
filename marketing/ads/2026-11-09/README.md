# The feature reel, re-rendered November 9, 2026

`headpin-reel.mp4` is the feature reel from `../2026-10-21/`, captured again
from the app at 0.104.0 so every screen in it is the current one: the phone's
own controls, History's calendar and the bigger bag. The edit, the voice and
the music are unchanged.

| File | What it is |
| --- | --- |
| `headpin-reel.mp4` | 1080 x 1920, 33 s. Same beats as before: one league night, then the free features under the teal "Free" pill, ending on "Free on the App Store". Made by `scripts/ad-content/reel/` (see its README). |

It shows only what the free app has, and nothing Pro.

**Run it only once the store holds a build made from 0.104.0 or later.** 1.0,
the build in App Review as this was made, is from about 0.69 and looks
different on every screen in the reel, so a bowler who installs 1.0 from this
ad would not find what it showed ("Which set goes with which build" in
`docs/APP-STORE-LISTING.md`). If the store build is from a later commit than
this, render it again from that commit.
